# 올팍 주차 예보 · Olympic Park Parking Forecast

올림픽공원 주차장(입출차 기록이 있는 동2·남2·북2문 구역)에 **언제 도착하고 언제 나서야 덜 붐빌까?** 한국체육산업개발(주) 공공데이터로 날짜·시간별 주차 혼잡을 미리 보여 주는 웹 서비스입니다. (한국어 / English)

- 서비스: https://inwoonull.github.io/olpark-parking-forecast/
- 2026 한국체육산업개발 공공데이터 활용 경진대회 출품작

## 사용한 공공데이터 (data.go.kr, 한국체육산업개발주식회사)
| 데이터 | 번호 | 쓰임 |
|---|---|---|
| 올림픽공원 입출차 정보 (2024.7, 215,528건) | 15138735 | 15분 단위 동시 주차 대수, 출차 몰림 시간 |
| 주차장 혼잡도 정보 (699건) | 15164156 | 주차구역별 만차 기록 비율 |
| 월별주차현황 (2023~2025) | 15131671 | 월별 보정 계수 |
| 영문 공연정보 | 15149169 | 날짜별 공연 표시, 대형 행사일 확인 |

## 계산 방법
1. 입출차 기록으로 15분마다 (누적 입차 − 누적 출차) = 동시 주차 대수
2. 평일 / 주말 / 대형 행사일(동시 주차 1,500대 이상: 2024-07-20·21)로 나눠 시간대별 평균
3. 평일·주말은 월별 주차대수 일평균의 3년 중앙값 ÷ 2024년 7월 일평균으로 보정(대형 행사일은 보정 안 함). 7/1은 6월 입차분이 빠져 제외
4. 단계(한산·보통·붐빔·매우 붐빔)는 주차장 혼잡도 기록 699건으로 보정: 기록 시점 예보값이 900·1,050·1,200대 경계를 넘을수록 실제 만차 기록 비율 21%→28%→39%→58% (순위상관 0.33, 날짜 단위 부트스트랩 95% 구간 0.17~0.48; 시각만 쓴 기준 모델은 0.06)

한계: 입출차는 2024년 7월 한 달 자료이고 전체 주차면수가 공개되지 않아 상대 등급으로 표시합니다. 실시간이 아닌 과거 패턴 기반 예보입니다.

## 다시 만들기
`data_raw/`에 위 4개 CSV를 내려받아 두고 `python scripts/build_data.py` → `data.json` 생성 (pandas, numpy). 서비스는 정적 HTML 한 장이라 서버 비용이 없습니다.
